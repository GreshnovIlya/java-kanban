# java-kanban
Приложение для ведения расписания задач с сохранением данных в файл file.csv
## Функционал
### Управление задачами
Создание, обновление и удаление задач, эпиков и их подзадач;
Управление статусом задач и подзадач: NEW, IN_PROGRESS, DONE;
Автоматическое управление статусом и временем выполнения эпиков на основе поздадач.
### История задач
Просмотренные или измененные задачи будут сохранятся в истории;
Можно просмотреть историю задач.
